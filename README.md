# 🇬🇧 English

## About

**Stickman Battle** is a fast-paced browser fighting game where customizable stickmen fight across floating platforms while dealing with dangerous environmental hazards.

The game is built with **HTML5 Canvas and JavaScript** and runs directly in a modern web browser.

## ✨ Features

* 🥊 Stickman fighting
* 🎨 Character customization
* 🔫 Multiple weapons
* 🛡️ Armor pickups
* 🏗️ Floating parkour platforms
* 🌋 Rising lava
* ☄️ Falling asteroids
* 💥 Explosions
* ☢️ Nuclear radiation
* ⚡ Super Ray
* 🔥 Volcano fireballs
* 🤖 CPU opponents
* 👥 Local multiplayer
* 🗺️ Multiple worlds
* 📺 Full-screen support

Platforms are dynamically generated around the arena, creating a constantly changing parkour-style battlefield.

## 🔫 Weapons

The game includes a variety of weapons:

* Uzi
* Sword
* Bat
* Spear
* Bow
* Gatling
* Bomb
* Nuke

Weapons can spawn on platforms during battles.

## 🛡️ Armor

Armor pickups include:

* Light Armor
* Medium Armor
* Heavy Armor

Armor can spawn on the floating platforms during a match.

## 🗺️ Worlds

Choose from different battle environments, including:

* 🌳 Meadow
* 🏜️ Desert
* 🌃 Night City
* 🌋 Volcano
* ❄️ Snow Peak

The Volcano environment includes additional fireball hazards.

## 🎮 Game Modes

Available game modes include:

* **1 vs 1 CPU**
* **1 vs 2 CPUs**
* **1 vs 3 CPUs**
* **2 Player Multiplayer**

CPU fighters are automatically controlled by the game.

## 🎨 Character Creator

Create your own fighter before entering battle.

You can customize:

* Character name
* Character color
* RGB color values
* Character size
* Health
* Speed
* Damage
* Jump

The game also supports different character sizes and customizable stats.

## 🕹️ Controls

### Player 1

| Key     | Action         |
| ------- | -------------- |
| `A`     | Move left      |
| `D`     | Move right     |
| `W`     | Jump           |
| `F`     | Punch / Attack |
| `G`     | Kick           |
| `Q`     | Aerial combo   |
| `SPACE` | Super Ray      |

### Menus

| Key     | Action           |
| ------- | ---------------- |
| `W / S` | Navigate         |
| `↑ / ↓` | Navigate         |
| `A / D` | Change selection |
| `F`     | Confirm          |
| `K`     | Confirm          |
| `ENTER` | Confirm          |
| `SPACE` | Confirm          |

Character creation also supports typing a name, Backspace for deletion, and RGB channel controls.

## ⚠️ Hazards

Watch out for:

### 🌋 Rising Lava

Lava rises during the battle, forcing fighters to move upward through the floating platforms.

### ☄️ Asteroids

Asteroids can fall into the arena and damage fighters. Large impacts can also destroy platforms.

### 🔥 Fireballs

The Volcano stage can spawn dangerous fireballs.

### 💣 Explosions

Explosive weapons can cause large attacks and environmental destruction.

### ☢️ Radiation

Nukes can create dangerous radiation clouds that remain active after the explosion.

The game visually tracks explosions, nukes, radiation clouds, Super Rays, asteroids, fireballs, and debris during combat.

## ⚡ Super Ray

Build your Super meter by fighting.

Once charged, use:

`SPACE`

to unleash the Super Ray.

The Super meter is displayed on the HUD together with health and wins.

## 🏆 Victory

Defeat the opposing fighters and be the last stickman standing.

The HUD displays each fighter's:

* Health
* Super meter
* Wins
* Alive / eliminated status

## ▶️ How to Run

1. Save the game as an `.html` file.
2. Open it using a modern web browser.
3. Click the screen or press any key to start.
4. Choose a game mode.
5. Create your character.
6. Select a world.
7. Fight!

For full-screen gameplay, use:

`F11`

## 🛠️ Technology

* HTML5
* JavaScript
* HTML5 Canvas
* Web Audio / browser APIs

No external game engine is required.

# 🇨🇳 中文

## 游戏简介

**《火柴人大战》**是一款快节奏的浏览器火柴人战斗游戏。

玩家可以创建自己的火柴人，在充满浮空平台、岩浆、陨石、爆炸和各种危险的竞技场中战斗。

游戏使用 **HTML5 Canvas + JavaScript** 制作，可以直接在现代浏览器中运行。

## ✨ 游戏特色

* 🥊 火柴人战斗
* 🎨 自定义角色
* 🔫 多种武器
* 🛡️ 护甲系统
* 🏗️ 浮空跑酷平台
* 🌋 岩浆上升
* ☄️ 陨石攻击
* 💥 爆炸
* ☢️ 核辐射
* ⚡ 超级射线
* 🔥 火山火球
* 🤖 CPU 对手
* 👥 本地双人
* 🗺️ 多种地图
* 📺 全屏支持

游戏会动态生成浮空平台，让战斗变成不断移动的跑酷式竞技场。

## 🔫 武器

游戏中拥有多种武器：

* Uzi 冲锋枪
* 剑
* 球棒
* 长矛
* 弓
* 加特林
* 炸弹
* 核弹

武器会在战斗过程中出现在浮空平台上。

## 🛡️ 护甲

游戏中有三种护甲：

* 轻型护甲
* 中型护甲
* 重型护甲

护甲会随机出现在竞技场的平台上。

## 🗺️ 游戏世界

目前可以选择多个战斗场景：

* 🌳 草地
* 🏜️ 沙漠
* 🌃 夜间城市
* 🌋 火山
* ❄️ 雪山

火山地图拥有额外的火球危险。

## 🎮 游戏模式

游戏支持：

* **1 vs 1 CPU**
* **1 vs 2 CPU**
* **1 vs 3 CPU**
* **双人本地对战**

CPU 对手会由游戏自动控制。

## 🎨 角色创建器

进入战斗前，你可以创建自己的火柴人。

可以调整：

* 角色名称
* 角色颜色
* RGB 颜色
* 角色大小
* 生命值
* 移动速度
* 攻击伤害
* 跳跃能力

## 🕹️ 操作方式

### 玩家 1

| 按键      | 功能      |
| ------- | ------- |
| `A`     | 向左移动    |
| `D`     | 向右移动    |
| `W`     | 跳跃      |
| `F`     | 拳击 / 攻击 |
| `G`     | 踢击      |
| `Q`     | 空中连击    |
| `SPACE` | 超级射线    |

### 菜单操作

| 按键      | 功能   |
| ------- | ---- |
| `W / S` | 上下选择 |
| `↑ / ↓` | 上下选择 |
| `A / D` | 调整选项 |
| `F`     | 确认   |
| `K`     | 确认   |
| `ENTER` | 确认   |
| `SPACE` | 确认   |

创建角色时，可以直接输入名字，使用 Backspace 删除文字，并通过 Q/E 切换 RGB 通道。

## ⚠️ 危险

战斗中需要注意各种危险。

### 🌋 上升的岩浆

岩浆会不断上升。

玩家必须不断跳跃和移动到更高的平台，否则可能被岩浆吞没。

### ☄️ 陨石

陨石会从天空落下，对玩家造成伤害。

大型陨石甚至可能摧毁平台。

### 🔥 火球

火山地图会出现危险的火球。

### 💣 爆炸

炸弹和其他爆炸攻击可以造成范围伤害。

### ☢️ 核辐射

核弹爆炸后会产生危险的辐射云。

玩家进入辐射区域后会持续受到伤害。

游戏会同时处理爆炸、核爆、辐射云、超级射线、陨石、火球以及平台碎片等效果。

## ⚡ 超级射线

通过战斗攻击积累超级能量。

当能量充满后，按：

`SPACE`

释放强大的超级射线。

HUD 会显示生命值、超级能量和胜场等信息。

## 🏆 胜利条件

击败所有敌人，成为最后一个存活的火柴人。

游戏 HUD 会显示：

* 生命值
* 超级能量
* 胜场
* 存活 / 淘汰状态

## ▶️ 如何运行

1. 将游戏保存为 `.html` 文件。
2. 使用现代浏览器打开。
3. 点击游戏画面或按任意键开始。
4. 选择游戏模式。
5. 创建你的角色。
6. 选择地图。
7. 开始战斗！

如果需要全屏：

`F11`

## 🛠️ 使用的技术

* HTML5
* JavaScript
* HTML5 Canvas
* Web Audio / 浏览器 API

**无需安装游戏引擎。**
